# Korean Learning App

## Commands

### Run Locally
Start the development server:
```bash
npm run dev
```

### Build
Build the project for production:
```bash
npm run build
```

### Deploy
Build and deploy to GitHub Pages:
```bash
npm run deploy
```

## Terminal Practice
Run terminal-based personal flashcard practice (login + folder selection + typing drill):
```bash
python3 terminal_flashcard_practice.py
```

### Terminal Shortcuts
- In folder menu:
  - Arrow keys: move selection
  - `Enter`: open folder
  - `Shift+R`: refresh folders
  - `Shift+Q` / `Esc`: quit
- In mode menu (after selecting a folder):
  - Arrow keys: move selection
  - `Enter`: open selected mode
  - `Esc`: back to folder menu
- In study mode:
  - `1`: previous card
  - `3`: next card
  - `Esc`: back to mode menu
- In practice:
  - `Enter`: submit answer
  - `0`: show/hide hint
  - `1`: previous card
  - `3`: next card
  - `5`: clear input
  - `Esc`: back to mode menu
